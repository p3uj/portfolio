# Portfolio Website

A modern personal portfolio built with Next.js, React, TypeScript, and Sass. This portfolio showcases a clean homepage, about me, project previews, and a contact section with direct email and phone details.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Node.js >= 20.0

## 🚀 Getting Started

Follow the steps below to run this portfolio locally on your machine.

1. Clone the repo

```bash
git clone https://github.com/p3uj/portfolio.git
```

2. Navigate into the project directory

```bash
cd portfolio
```

3. Install dependencies

```bash
npm install
```

4. Copy `env.example` to `env.local` and update the variables for your local environment

```bash
cp .env.example .env.local
```

5. Start the development server

```bash
npm run dev
```
